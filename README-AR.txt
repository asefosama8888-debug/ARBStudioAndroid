ARB Studio Android - نسخة أولية

بناء APK من الهاتف عبر GitHub Actions:
1) ارفع محتويات المشروع إلى مستودع GitHub.
2) افتح تبويب Actions وشغّل Build ARB Studio APK.
3) بعد نجاح البناء نزّل artifact باسم arb-studio-debug-apk وفك الضغط وثبّت APK.

هذه النسخة هي تطبيق Android حقيقي يحتوي على محرر ومعاينة أولية. إنشاء APK للمشاريع التي تصنعها من داخل ARB Studio مرحلة تالية؛ لن ندّعي أن النسخة الحالية تنتجها بالفعل.
